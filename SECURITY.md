# Security reporting

NCM-MLX is experimental research software. Security fixes target the current release and `main`; older experimental revisions do not have a separate maintenance commitment.

For a vulnerability, check the repository's [security advisories](https://github.com/janmus1c/ncm-mlx/security/advisories). If **Report a vulnerability** is available, use that private form. If it is unavailable, open an issue requesting a private reporting channel without including exploit details or sensitive information. Do not disclose credentials or a working exploit in a public issue.

Include the affected release or commit, a minimal reproduction, expected impact and any proposed mitigation in the private report. Remove unrelated personal data and infrastructure details. Do not upload third-party datasets or model weights without permission. This project makes no guaranteed response-time or bounty commitment.

Ordinary installation faults, training-quality questions and incorrect scientific claims belong in the public [issue forms](https://github.com/janmus1c/ncm-mlx/issues/new/choose), with private information removed.
